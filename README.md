자바 웹(2) 포토폴리오 만들기 프로젝트

프로젝트 소개

자바 웹 수업에서 배운 내용을 바탕으로 웹 페이지를 만들고 회원 관리 기능과 REST API를 구현했습니다. 
주차별 실습을 진행하면서 데이터베이스 연동, 로그인, 권한 관리 등의 기능을 적용했습니다.

주차별 실습 내용

2주차 - Model 데이터 전달

Model에 데이터를 담아 HTML 화면에 출력하는 기능을 구현했습니다.

3주차 - 포트폴리오 페이지

카테고리별 포트폴리오 화면을 만들고 아이콘과 링크를 연결했습니다.

4주차 - 데이터베이스 연동

TestDB를 활용해 ID, 이름, 나이, 성별 데이터를 관리하고 웹 페이지에서 조회했습니다.

5주차 - 회원가입과 로그인

비밀번호 확인 검증과 BCrypt 암호화를 적용하고 로그인 상태 유지 기능을 구현했습니다.

6주차 - 회원 권한 관리

USER, MANAGER, ADMIN 권한을 구분하고 권한에 따른 접근 제한과 관리자 본인 계정 보호 기능을 구현했습니다.

7주차 - REST API

회원 아이디와 이름을 검색하는 API를 만들었습니다. 검색 결과가 없을 때 빈 배열이 반환되도록 했으며, RestControllerAdvice를 활용해 공통 예외 처리 기능도 구현했습니다.

문제 해결 및 배운 점

실습 중 검색어를 입력해도 전체 회원이 조회되는 문제가 있었습니다. 컨트롤러에서 전체 조회 메서드를 호출하고 있다는 점을 확인하고 검색 메서드를 연결해 해결했습니다.

또한 Postman으로 API를 테스트하면서 요청 방식과 주소, 응답 상태 코드를 확인하는 방법을 익혔습니다. 예외 처리 코드를 별도 클래스로 분리하면서 코드 중복을 줄이는 방법도 배웠습니다.

느낀 점

수업에서 배운 내용을 실제 프로젝트에 적용하면서 각 기능이 어떻게 연결되는지 이해할 수 있었습니다. 오류가 발생했을 때 메시지와 코드를 하나씩 확인하며 원인을 찾는 과정이 중요하다는 것을 느꼈습니다. 앞으로도 기능이 작동하는 것뿐 아니라 코드의 동작 원리까지 이해하면서 개발하고 싶습니다.
